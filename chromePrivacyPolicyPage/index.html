摸鱼助手 隐私权政策

生效日期：2026-08-01 · 最近更新：2026-11-23 · 适用于浏览器扩展「摸鱼助手」

1. 概述

「摸鱼助手」是一款浏览器扩展，用于在独立的手机尺寸弹窗中集中打开并切换小红书、知乎、微博、抖音、 新闻简报、摸鱼日历、历史上的今天及挖矿工厂等休闲内容，并提供收起/恢复、透明度与小红书深色模式等设置。 我们重视您的隐私，本政策说明扩展如何处理相关数据。

2. 我们收集 / 处理哪些数据

本扩展主要在您的设备本地运行，不运营用于收集用户画像的后端账号系统。

  • 本地设置数据：例如小红书深色模式开关、窗口透明度、当前选中的应用、弹窗窗口标识及是否收起等， 保存在浏览器本地 storage 中，用于恢复您的偏好与弹窗状态。
  • 网站内容（本地处理）：在受支持网站上，内容脚本会读取并调整页面 DOM， 以便在手机尺寸弹窗中获得更好的布局与低干扰浏览体验。这些处理在本地完成，不会把页面正文上传到开发者服务器。
  • 当前标签信息（有限使用）：为在同一弹窗内识别/切换应用，扩展可能读取其管理窗口中当前标签的 URL。 扩展不会建立或上传您的完整上网历史记录。
  • 快捷键事件（本地处理）：为在浏览器未自动绑定扩展快捷键时仍可使用 Alt+Q， 扩展会在普通网页中运行轻量脚本并仅判断是否按下指定组合键。扩展不会记录、保存或上传用户输入的其他按键内容。
  • 内容接口请求：当您使用随机语录、新闻简报、摸鱼日历或历史上的今天等功能时， 扩展会向内容接口请求对应数据。请求不携带扩展中保存的用户设置、网页正文或账号凭据； 但接口服务商可能按照互联网服务的常规方式接收到您的 IP 地址、浏览器类型、请求时间等基础网络信息。
  • 打赏相关：若您点击打赏入口，扩展可能检测打赏页面是否可达并打开该网页。 该过程不收集您的支付信息；支付与订单由您访问的第三方页面自行处理。

3. 我们不做什么

  • 不出售用户数据；
  • 不将用户数据用于与「多应用手机弹窗浏览」无关的目的；
  • 不将用户数据用于信用评估或放贷；
  • 不从远程服务器下载或执行远程 JavaScript 代码；
  • 不收集密码、通讯内容、精确位置、健康或金融账户信息。

4. 数据存储与保留

设置数据仅存储在您的浏览器本地。卸载扩展或清除扩展数据后，相关本地设置通常会被移除。 开发者不会在自有服务器上长期保存您的浏览内容副本。

您可以通过浏览器的扩展管理页面清除扩展数据或卸载扩展，以删除保存在本地的设置和窗口状态。

5. 权限说明

  • storage：保存深色模式、透明度、当前入口及弹窗状态等本地设置。
  • tabs：识别扩展弹窗中的当前入口、切换标签页 URL，以及在用户主动点击时打开相关页面。
  • windows：创建、聚焦、最小化、恢复及复用独立手机尺寸弹窗。
  • 主机权限：在受支持的网站运行布局适配脚本、请求新闻/语录等内容接口、检测打赏页面是否可达， 并在普通网页中提供 Alt+Q 快捷隐藏/恢复能力。

6. 第三方服务

您在小红书、知乎、微博、抖音等网站上的登录与内容浏览，受相应网站自身隐私政策约束。 本扩展不控制这些第三方网站的数据处理行为。

新闻简报、随机语录、日历和历史内容由第三方内容接口提供；挖矿工厂和支持作者页面也是独立的第三方网站。 当您使用这些功能时，浏览器会直接连接对应服务，其数据处理行为受相应服务的隐私政策和服务条款约束。 扩展不会将本地设置、其他网页内容或完整浏览历史主动发送给这些第三方。

7. 儿童隐私

本扩展面向一般用户的效率/浏览辅助场景，不以儿童为主要服务对象，也不会故意收集儿童个人信息。

8. 政策更新

我们可能适时更新本政策。更新后将在本页面公布修订版本及生效日期。

9. 联系我们

如对本隐私权政策或数据处理有疑问，请通过您发布扩展时在 Chrome 网上应用店留下的开发者联系邮箱与我们联系。 我们将在合理期限内予以回复。
